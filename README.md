# 📚 StudyNest — Premium Student Workspace

> **Your All-In-One Student Command Centre** 🚀  
> *Track attendance, manage grades, organize schedules, master habits, write smart notes, and boost study focus—all in one beautiful, distraction-free workspace.*

---

## 🌟 Overview

**StudyNest** is a feature-packed, progressive web application designed to help students stay organized, focused, and academically successful. Designed with a clean aesthetic, dark/light theme switching, and desktop & mobile-optimized layouts, StudyNest brings every aspect of student life under one digital roof.

---

## ✨ Features Deep-Dive

### 1. 🔐 User Authentication & Personalization
- 👤 **Secure Authentication**: Dedicated Sign In and Sign Up screens with validation.
- 🎨 **Avatar & Accent Color Customization**: Pick from custom avatar icons (🦁, 🐯, 🦊, 🐼, 🦋, 🚀, ⚡, 🌙) and vibrant theme colors.
- 🎓 **Academic Grade Selector**: Customized for Class VI through Class XII, as well as 1st to 3rd-year university levels.
- 🔒 **Account Utilities**: Password recovery ("Forgot Password" modal) and embedded Terms of Service & Privacy Policy dialogs.

---

### 2. ⚡ Interactive Dashboard
- 📊 **Key Metrics Summary**: Overview cards displaying real-time Attendance Rate %, Total Notes, Active Reminders, and Daily Classes count.
- 💬 **Motivational Quote Engine**: Daily inspirational quotes with single-click manual refresh button (↻).
- ⚙️ **Widget Customizer**: Toggle individual dashboard modules on or off for a tailored view.
- 🌓 **Theme Switcher**: One-click toggling between sleek Dark Mode and ambient Light Mode.

---

### 3. 📅 Attendance Tracker
- 🗓️ **Visual Calendar Heatmap**: Monthly and yearly grid views showing attendance trends.
- 🏷️ **Status Tagging**: Easily mark days as `Present` (green), `Absent` (red), or `Holiday` (purple).
- 📈 **Automated Analytics**: Real-time percentage calculation to help maintain minimum required attendance.

---

### 4. 🗓️ Schedule & Timetable Manager
- ⏰ **Weekly Grid Layout**: Hour-by-hour view of classes and academic commitments.
- 📍 **Live Time Indicator**: Red current-time bar overlaid directly on today's schedule grid.
- 🎨 **Course Category Pills**: Color-coded subject slots for quick visual recognition.

---

### 5. 🔔 Smart Reminders & Homework Tracker
- 🚨 **Priority Badges**: Mark tasks as **High** 🔴, **Medium** 🟡, or **Low** 🟢 priority.
- 🏷️ **Subject Tagging**: Organize assignments by subjects (Math, Science, History, Languages, etc.).
- 📌 **Sidebar Badge Indicator**: Live counter showing pending high-priority tasks.

---

### 6. 📊 Gradebook & Performance Tracker
- 📝 **Subject Grade Table**: Log marks, assignments, and exam results.
- 🏅 **Visual Grade Badges**: Automatic grading scale representation (`A` 🟢, `B` 🔵, `C` 🟡, `D` 🔴).

---

### 7. 📝 Smart Notes with Markdown Editor
- 🛠️ **Built-In Markdown Toolbar**: Formatting buttons for Headings (`H1`, `H2`), **Bold**, *Italic*, `Inline Code`, Blockquotes, Lists, and Code Blocks.
- 👁️ **Live Render & Modal View**: Read and edit notes in full-screen modal overlays.
- 🗂️ **Categorized Card Grid**: Colored top border accents per card and quick deletion.

---

### 8. 🃏 Active Recall Flashcards Deck
- 🎴 **3D Card Flip Animation**: Interactive front/back card study view.
- ⭐ **Spaced Repetition Rating**: Rate recall difficulty on a 0 to 3 scale (Again, Hard, Good, Easy) for effective memory retention.
- 📁 **Deck Management**: Create and manage multiple study decks per subject.

---

### 9. 📆 Study Planner & Drag-and-Drop Grid
- ⏱️ **Block Scheduling**: Map out dedicated study blocks across days of the week.
- 📊 **Planned vs. Actual Hours**: Visual comparison bar graphs tracking study targets vs. real effort.
- 🎨 **Subject Palette**: Custom drag-and-drop color blocks per subject.

---

### 10. ⏱️ Pomodoro Timer & Focus Sessions
- 🔔 **Multiple Timer Modes**: Switch seamlessly between **Focus** (25 min), **Short Break** (5 min), and **Long Break** (15 min).
- ⭕ **Visual Ring Display**: Modern circular countdown timer.
- 📜 **Session Logging**: Log completed focus blocks per subject for productivity analysis.

---

### 11. 🎯 Habit Tracker & Heatmap Analytics
- 🔥 **Streak Tracker**: Animated flame icon indicating current active habit streaks.
- 🟩 **GitHub-Style Heatmap**: Year-round matrix displaying daily activity logs.
- 📊 **Weekly Bar Breakdown**: Visual completion percentages per day.
- 😃 **Custom Habit Emoji Picker**: Personalize habit cards with custom emojis.

---

### 12. 📱 Mobile & Responsive UI/UX
- 🍔 **Hamburger Drawer Menu**: Smooth sliding sidebar drawer on mobile devices.
- 📱 **Bottom Navigation Bar**: Native app-like tab bar for quick access to Home, Schedule, Habits, and Notes on mobile.
- ↔️ **Collapsible Sidebar**: Desktop sidebar shrinks into icon-only mode with floating tooltips.
- 📲 **PWA Ready**: Manifest file included for native installation on Android, iOS, and Web.

---

## 🛠️ Tech Stack & Architecture

- **Frontend**: Pure HTML5, CSS3 (Custom CSS Variables, CSS Grid, Flexbox, Keyframe Animations), Vanilla JavaScript (ES6+).
- **Typography**: Google Fonts (*Manrope* for bold headers & *DM Sans* for clean body typography).
- **Design System**: Fully variable-driven color tokens with dark mode fallback rules.
- **PWA Support**: SVG inline favicon & Web App Manifest integration (`manifest.json`).

---

## 💻 How to Run

1. Clone or download the repository.
2. Open `index.html` in any modern web browser (Chrome, Firefox, Safari, Edge).
3. No server setup or Node.js dependencies required — 100% lightweight client-side execution!
